# gc-minimal-zine-poster-v0-3

## 快速判断

`gc-minimal-zine-poster-v0-3` 用于把主题、文章、照片或参考图转成带纸张质感的极简 ZINE 海报。它固定保留大片留白、一个清楚的视觉事件、克制排版和一处高纯度色彩，既可以直接出图，也可以先分析参考图或只生成 Prompt。

## 适合场景

- 你有一句主题、文章构想或情绪，想制作一张安静的纸刊风海报。
- 你希望把人物、物件或日常照片作为海报主体，同时保留可识别的照片信息。
- 你有一组参考图，想提炼可复用的视觉系统，而不是复制其中的文字或构图。
- 你需要一条可直接交给图片模型使用的完整 Prompt。

## 前置要求

- 具备图片生成能力的运行环境。
- 参考图分析和照片输入需要运行环境能够读取实际图片文件。
- 可选提供主题、短文字、文章、照片、内容简报或参考图集。

## 输入与输出

输入：

- 主题、句子、文章、物件、情绪、照片或参考图集。
- 可选的保真要求、文字语言、版式倾向和批量变化要求。

输出：

- 默认输出一张成品海报和最终生图 Prompt。
- 可选输出照片保真说明、版式配方、参考图风格系统、可复用 Prompt 或多种同系版式。

## 核心特色

- 留白是版式的一部分：默认画面中大部分区域保持安静，只保留一个小而明确的视觉焦点。
- 照片处理有边界：会区分照片是编辑目标、风格参考还是辅助插入，并按保真等级约束生成。
- 参考图分析不复刻身份：区分固定视觉规则、可变规则和样本残留，避免沿用原图文字、品牌或构图。
- 有明确质量门：检查色彩强调、主体、纸感、稀疏度，以及照片主体是否仍然可识别。

## 和相近技能的差异

- 相比 [photo-abstract-editorial](photo-abstract-editorial.md)，它不以照片为唯一输入，也支持主题、文章和参考图分析；成图追求纸张纹理与稀疏 ZINE 海报，而非固定的“原照片 + 抽象面板”结构。
- 相比 [gathered-scenes-zine-skill](gathered-scenes-zine-skill.md)，它更偏可复用视觉系统和 Prompt 编排；后者专注从一张照片出发，在实景拼贴与影像蒸馏两条路径中创作。

## 工作流程

1. 判断请求属于直接生成、照片输入、参考图分析、仅 Prompt 或分析后生成。
2. 阅读内容或实际图片，确定主题、视觉隐喻与照片保真边界。
3. 选择版式、视觉焦点、排版、纸张、色彩和变化方案。
4. 生成并检查实际结果，必要时收紧 Prompt 后再生成一次。
5. 返回成图、最终 Prompt、配方或风格规则。

## 当前限制

- 图片模型会影响最终纸感、文字准确性和照片保真度，长文本尤其容易失真。
- 默认视觉方向是稀疏、纸刊和非商业化的海报，不适合满版促销广告或复杂信息图。
- 参考图只应用于学习视觉语法，不应用于复制原图身份。
