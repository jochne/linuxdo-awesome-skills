# photo-abstract-editorial

## 快速判断

`photo-abstract-editorial` 把一张上传照片制作成竖版编辑作品：原照片保留在主要区域，另一部分是完全从照片关系推导出的抽象记忆面板，再加一个简短原创英文标题。它不是滤镜、重画或风格迁移。

## 适合场景

- 你想保留一张旅行、街拍或日常照片的真实内容，同时让它成为更有叙事感的编辑作品。
- 你希望从照片的空间、光线、色彩和节奏中提取抽象图形，而不是套用通用装饰。
- 你需要极简档案海报、照片加抽象双联画或视觉记忆面板。

## 前置要求

- 一张可上传的照片。
- 具备图片生成能力的运行环境。
- 使用范围限于个人、教育、研究与非商业用途；商业使用须取得作者授权。

## 输入与输出

输入：

- 一张照片。
- 可选的画布比例、照片与面板占比、抽象程度和标题倾向。

输出：

- 一张完整的竖版编辑作品：原照片、象牙色抽象面板和原创英文标题。

## 核心特色

- 原照片保持真实：只允许为版式做等比缩放或轻微裁切，不重画、扩展、修图或套滤镜。
- 抽象面板可追溯：重要图形只来自照片的空间、色彩和结构事实。
- 版式克制：面板是平整的中性色象牙底，不引入渐变、纸纹、阴影、拼贴和多余装饰。
- 标题只服务画面：标题为基于可见事实创作的两到五词英文短语，避免日期、Logo、水印和说明文字。

## 和相近技能的差异

- 相比 [gc-minimal-zine-poster](gc-minimal-zine-poster.md)，本项目只能从一张照片出发，且严格保留原照片；前者还支持主题、文章、参考图分析和纸刊质感海报。
- 相比 [gathered-scenes-zine-skill](gathered-scenes-zine-skill.md) 的实景拼贴，本项目不采用手撕边界、纸张纹理或自由插画场，抽象面板也必须保持克制的平面结构。

## 工作流程

1. 检查照片中的主体关系、尺度、方向、重叠、光线、色彩与留白。
2. 保留原照片作为上方或主要区域。
3. 将少量关键关系转化为下方的稀疏抽象母题。
4. 在统一象牙色面板上完成竖版构图与英文标题。
5. 只返回完成的单张作品。

## 当前限制

- 必须有一张照片；不适合仅凭文字主题从零生成。
- 原照片和抽象面板都有严格边界，无法用于大幅改写人物、物体或场景。
- 作者的许可不允许未经授权的商业使用、商业分发或作为商业产品的一部分使用。
