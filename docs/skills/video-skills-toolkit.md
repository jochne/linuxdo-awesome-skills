# video-skills-toolkit

## 快速判断

`video-skills-toolkit` 是一组基于 Remotion 的视频生产 agent skills 工具包。它把整本书、文章或数学证明自动转成长视频，核心心法是“字幕文件驱动一切”：先写逐字稿、生成配音，再用字幕作为唯一时间轴基准去排布画面与动画。

## 适合场景

- 你想把一本书、一份长文档或一系列文章，自动做成带配音和动效的长视频教程。
- 你需要把微信公众号文章转成保留原文图的 Studio 风格视频。
- 你想做数学证明 / 几何动画（3Blue1Brown、可汗学院风格）或算法可视化。
- 你想做纸片风分层动画（历史、科普、商业故事、人物关系）。
- 你想做“小白学 AI”这类手绘故事视频。
- 你需要把音频 / 视频转成字幕和逐字稿。

## 输入与输出

输入：

- 逐字稿（口语化也可），决定整条时间线长度与节奏
- TTS 音频（MiniMax 或免费 EdgeTTS）
- 可选：文章 URL、数学内容、图片 / 素材、Python 抠图环境

输出：

- 一条以声音为轴的时间线视频
- 字幕文件（SRT / VTT / JSON），作为整条视频唯一基准
- Remotion 工程（画面、动画、音效 / BGM 按字幕对齐）
- 低清 proof 与高清成片

## 核心特色

- 字幕驱动：视频是“以声音为轴的时间线”，字幕文件是整条视频唯一基准，画面、动画、音效全部对齐到它。
- 六类可复用模板：口播、公众号文章转视频、数学证明几何动画、纸片风分层动画、手绘故事、音频转字幕。
- 公众号文章转视频保留原文图（`object-fit: contain` 永不裁切）。
- 数学证明动画用代码绘制精准 SVG 几何，公式逐步揭示，深底高饱和风格。
- 纸片风分层模型把画面拆成背景 / 后排 / 主体 / 前景多层独立素材，每层按不同节奏运动。
- 配音可用 MiniMax，也可用免费 EdgeTTS，几乎免费跑通整条流水线。

## 工作流程

1. 写逐字稿（决定时间线长度和节奏）。
2. 用 TTS 生成音频（MiniMax 或免费 EdgeTTS）。
3. 拿到字幕文件，作为整条视频唯一基准。
4. 用字幕驱动所有画面与动画。
5. 叠加音效与 BGM。
6. 低画质调试确认。
7. 出高画质成片。

## 当前限制

- 视频工程基于 Remotion，需要 Node.js 环境与 `npm install` / 构建。
- 配音依赖外部 TTS / API（MiniMax 或 EdgeTTS 等），仓库不含密钥。
- 纸片等分层动画需要素材生成与绿幕抠图链路。
- 公众号文章转视频依赖 `mp.weixin.qq.com` 可访问性。
- 它是一组技能模板集合，不是单一成片项目。
