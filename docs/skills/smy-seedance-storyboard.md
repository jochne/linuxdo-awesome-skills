# smy-seedance-storyboard

## 快速判断

`smy-seedance-storyboard` 是由 `liangdabiao` 基于开源项目 `Seedance2-Storyboard-Generator` 二次开发的**上美影风格（上海美术电影制片厂复古手绘动画）Seedance 2.0 短剧分镜技能**。你只需提供一句话创意、小说、神话或民间故事，它就会输出全套中文、直接复制可用的剧本、本剧专用矿物颜料色盘、资产出图提示词、每集 13-15 秒分镜脚本与尾帧衔接说明，主打“极致简单、不做重自动化、保留人工微调空间”。

## 适合场景

- 你想把中国神话典故、水浒志怪、历史故事或小说改编成《大闹天宫》《天书奇谭》《九色鹿》味道的复古国风动画短剧。
- 你希望跨集保持画风与色彩高度稳定，避免 AI 自动把二维动画渲染成油画渐变或 3D 体积感。
- 你想在即梦、Seedream、豆包或 Midjourney + Seedance 2.0 中手动出图出片，不希望被复杂的自动化脚本绑定流程。
- 你需要石蓝淡墨绘本、水墨淡彩、剪纸风或敦煌重彩等不同子风格的国风短剧模板，或想在此基础上二开自己的专属画风 skill。

## 前置要求

- **故事素材**：一句话创意、小说、神话典故或故事大纲。
- **AI 绘图平台**：即梦 / Seedream / 豆包（中文提示词直用），或 Midjourney / GPT-Image-2（可选英文版）。
- **AI 视频平台**：Seedance 2.0（支持上传参考图 `@图片X` 与视频延长 `将@视频1延长15s`）。
- **后期剪辑**：任意外部剪辑软件，用于拼集以及补配说书人旁白、锣鼓配乐和字幕。

## 输入与输出

输入：

- 故事、小说、神话或民间传说（如“帮我做一个武松打虎的上美影短剧，5 集”）
- 简单确认集数、画幅（竖屏/横屏）、基调或子风格（不想回答可直接说“都用默认”）

输出：

- **完整剧本**：含核心梗、故事梗概、人物小传（含专属主色与纹样）、分集大纲与 `△` 分镜正文（含说书人旁白体制、OS/VO、闪回与字幕标注）
- **剧组色盘声明**：中英双语矿物颜料色盘字符串（如朱砂红/鎏金/墨黑/青瓷绿），全剧逐字引用防跑色
- **资产提示词列表**：角色（标准资产版/海报版/四视图）、场景（正打/反打/侧面全景）、异兽与道具的中文与英文对照出图提示词
- **Seedance 2.0 分镜提示词**：每集 13-15 秒时间轴分镜，首行固定风格行 + 色盘，含 `@图片X` 参考与尾帧描述
- **修补表**：针对残次镜头的分镜出图提示词（先出分镜图再图生视频）

## 核心特色

- **防跑偏三件套**：以 `references/上美影风格指南.md` 为唯一事实来源，每条生图提示词以固定“上美影风格咒语”开头、以咆哮体硬约束（`必须纯2D平涂！绝对不要阴影、不要渐变、不要3D体积感！必须大面积留白！`）结尾，并锁定全剧统一色盘，防止模型漂移成“油画感假上美影”。
- **图/视频双端配方分离**：图片端严格纯 2D 平涂无阴影无渐变；视频端则保留手绘墨线与水粉颜料笔触肌理，仅禁用 3D 渲染、写实感与体积光。
- **子风格与神怪造型规范**：除默认手绘平涂主线外，点名即可切换石蓝淡墨绘本、水墨淡彩、剪纸风、敦煌重彩四种子风格；遵循成人 5-7 头身、儿童 3-4 头身的概括比例与专属纹样体系。
- **规避写实审核限制**：上美影手绘动画造型天然避开写实真人脸部素材的平台审核拦截。
- **轻量化二开范本**：原帖明确主张“不要功能、不要自动化、不要干涉自由选择”，内置《鲁智深醉闹五台山》《罗刹市》两套完整示例项目，方便读者参考或二次定制自己的风格 skill。

## 和相近技能的差异

- 与同作者 `seedance-storyboard-generator-realman` 相比：`smy-seedance-storyboard` 专攻**上美影复古手绘纯 2D 动画**，刻意保持纯文档交付与高自由度（无内置 CLI 自动化出图流程），且 Seedance 声音段只写明确音效、不生成音乐与字幕；`seedance-storyboard-generator-realman` 专攻**真人实拍胶片电影质感与同期声口型同步**，并配套即梦 CLI 报价与生成流。
- 与同作者 `video-skills-toolkit` 相比：`video-skills-toolkit` 是基于 Remotion 的**代码化字幕驱动长视频生产线**（适合整本书教程、公众号文章转视频、数学证明等）；本技能专注于国风动画短剧的剧本、资产与 Seedance 分镜文档创作。

## 工作流程

1. **输入故事与设定**：给出故事想法或小说，确认集数、画幅、基调或子风格（支持全默认）。
2. **产出剧本与色盘**：生成含说书人旁白体制的分集 `△` 剧本，并声明本剧专用的中英双语矿物颜料色盘。
3. **生成资产参考图**：复制资产提示词（中文贴入即梦/Seedream/豆包，英文贴入 Midjourney）生成角色、场景、异兽与道具参考图。
4. **Seedance 2.0 分镜出片**：第 1 集上传参考图并用时间轴分镜提示词直接生成；第 2 集起上传上一集视频并附尾帧描述，以 `将@视频1延长15s` 保持衔接。
5. **外部剪辑完片**：在剪辑软件中拼接各集片段，补配说书人旁白、传统锣鼓配乐与字幕，必要时用分镜出图提示词修补残次镜头。

## 当前限制

- 本技能只生成剧本与提示词文档，不内置自动生图或自动剪辑程序，需要手动在绘图/视频平台及剪辑软件中完成成片。
- 受 Seedance 2.0 平台规格限制：单次生成最多挂 9 张参考图、最多 3 段参考视频（总计 15 秒），超过 300 词的复杂提示词或敏感词（如部分江湖帮派词汇）可能引发指令遵循下降或失败。
- 分镜中的【声音】部分仅生成明确环境音与动作音效，不生成配乐和字幕，成片音乐与旁白需后期补配。
- 原仓库未声明开源许可证（SPDX License 为空），用于商业项目或二次分发前需向作者确认授权。
- 必须保留固定风格块、纯 2D 平涂硬约束与慢动作描述，否则容易出现画面阴影渐变或动作崩坏。
